# BravoDesign — The Glitch Constructivist

Sitio web y portafolio de diseño de Tomás Bravo con estética constructivista y Neo-Memphis ética.

## 🚀 Vista Previa Rápida

Puedes abrir directamente el archivo `index.html` en tu navegador favorito, o iniciar un servidor local con Python:

```bash
python -m http.server 8000
```

Luego abre tu navegador en [http://localhost:8000](http://localhost:8000).

## 📁 Estructura del Proyecto

- `index.html`: Página principal del sitio web (HTML5 + Tailwind CSS + Google Fonts).
- `DESIGN.md`: Especificación de tokens de diseño, paleta de colores y tipografía.
- `screen.png`: Captura de pantalla de referencia del diseño.
- `.gitignore`: Archivos y carpetas del sistema ignorados por Git.

## 🌐 Publicación en GitHub Pages

1. Inicializa el repositorio Git:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for portfolio website"
   ```
2. Crea un repositorio en GitHub y conéctalo:
   ```bash
   git branch -M main
   git remote add origin https://github.com/Tbravop/bravodesign.git
   git push -u origin main
   ```
3. En la configuración de tu repositorio en GitHub (**Settings > Pages**), selecciona la rama `main` y la carpeta `/ (root)` para publicar tu sitio web gratis.
